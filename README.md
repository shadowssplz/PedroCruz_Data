# 📊 Pedro Cruz

**`Analista de Dados`**

Sou **Pedro Cruz**, de Fortaleza, Ceará. Trabalho como **Analista de Dados na TGA Construção e Segurança Viária**, onde desenvolvo BI de gestão de frota, pipelines de dados e integrações com plataformas de telemetria.

Estou concluindo o bacharelado em **Ciência da Computação no IFCE (Campus Aracati)**. Tenho cerca de 4 anos de experiência prática com dados, construída de forma autodidata, e gosto de transformar dados brutos e bagunçados em indicadores que ajudam a decidir.
